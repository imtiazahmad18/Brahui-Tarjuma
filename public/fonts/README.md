The supplied Jameel Noori Nastaliq font is self-hosted as `jameel-noori-nastaliq.woff2`.

To replace it later, replace this file using the same filename. Its `@font-face` is defined in `src/app/globals.css`, and its preload is in `src/app/layout.tsx`. The shared `--font-nastaliq` CSS variable applies it throughout the site.
